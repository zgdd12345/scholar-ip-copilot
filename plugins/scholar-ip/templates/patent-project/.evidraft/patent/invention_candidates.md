# Invention candidates

Populate via `/scholar:patent-scout`. One H2 section per candidate, id prefix `C-`,
zero-padded to three digits (C-001, C-002, ...). Every candidate must list:

- a short technical title,
- the problem it solves,
- the core technical idea (one paragraph),
- evidence ids backing its existence in the codebase,
- a preliminary novelty hypothesis (refined later by `/scholar:patent-prior-art`),
- a status flag.

Do **not** invent inventor names or filing dates here.
